Background Remover – Magic Eraser

A simple, lightweight browser-based image editor for removing unwanted parts of images and creating transparent PNGs.

✨ Features

- 🖼️ Upload images directly from your device
- 🧹 Magic Eraser brush
- ↩️ Restore erased areas
- ↶ Undo and redo
- ⟳ Reset image
- 🗑️ Clear canvas
- 🎚️ Adjustable brush size
- 🟦 Transparent background support
- 📥 Download edited images as PNG
- 📱 Responsive design for mobile and desktop
- 🔒 Image editing happens directly in the browser

🚀 How to Use

1. Upload an image.
2. Select Erase.
3. Paint over the unwanted area.
4. Use Restore if you remove something by mistake.
5. Adjust the brush size when needed.
6. Click Download Transparent PNG to save your result.

🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

No backend or API key is required for the basic editor.
